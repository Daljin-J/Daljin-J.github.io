# Daljin J — Academic Portfolio

A responsive, multi-page academic portfolio website designed for GitHub Pages.

## Pages
- `index.html` — Home
- `about.html` — Biography and academic background
- `research.html` — Research themes and projects
- `publications.html` — Publications and DOI
- `patents.html` — Patent/technology disclosure
- `skills.html` — Technical skills
- `contact.html` — Contact and professional links

## Publish with GitHub Pages
1. Create a public repository named `Daljin-J.github.io` in the GitHub account `Daljin-J`.
2. Upload all files and folders in this project to the repository root.
3. In repository Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`.
4. Wait for GitHub Pages to publish the site at https://daljin-j.github.io/.

## Before publishing
- Confirm the exact title, author list and complete citation for the 2026 *Vacuum* paper.
- Add official patent/application metadata and status.
- Add a professional email, LinkedIn, Google Scholar and ORCID URLs.
- Add a profile photograph if desired (save it as `assets/profile.jpg` and update the home page markup).
- Add a PDF CV, then link it from the navigation or home page.
- Check all academic facts, claims and links.

## Customize
- Edit page content in the corresponding `.html` file.
- Change colors and layout in `assets/style.css`.
- Navigation and responsive menu behavior are in `assets/site.js`.
- No build tools, frameworks or paid hosting are required.

## Theme switching
- Dark theme is the default.
- Use the sun/moon control at the top-right of any page to switch themes.
- The selected theme is saved in the visitor's browser and persists across pages.
